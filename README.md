Direct Windows NT syscall library generated by [SysWhispers3](https://github.com/klezVirus/SysWhispers3).

> ## 🚚 Moved
>
> Active development has moved to a standalone repo:
> **[github.com/Platon7788/SysCalls](https://github.com/Platon7788/SysCalls)** — the **RSC (RustSysCall)** stack.
>
> RSC is self-contained (no SysWhispers3), tracks signatures directly from
> `ntdll.pdb` via the Microsoft Symbol Server + `phnt`, covers 509 functions
> (Windows 10 19045 + Windows 11 26200 unioned), builds on stable Rust 1.88,
> and ships the canonical DB checked-in for zero-setup consumer builds.
>
> This repository is kept as a historical reference for the SW3-generated
> approach. No further updates are planned here.

> ⚠️ **Security Notice**: This library is intended for security research, red team operations,
> and legitimate security testing only. Misuse may violate laws and regulations.

## Overview

This crate provides direct syscall wrappers that bypass user-mode hooks typically installed by 
EDR/AV solutions. Instead of calling `ntdll!NtXxx` functions (which can be intercepted), 
the code directly executes the `syscall` instruction with the appropriate syscall number.

## Usage Examples

### Basic Memory Allocation

```rust
use syscalls::*;

unsafe {
    let mut base_addr: PVOID = core::ptr::null_mut();
    let mut region_size: SIZE_T = 0x1000; // 4KB
    
    let status = nt_allocate_virtual_memory(
        NtCurrentProcess(),      // Current process
        &mut base_addr,          // Output: allocated address
        0,                       // ZeroBits
        &mut region_size,        // In/Out: region size
        MEM_COMMIT | MEM_RESERVE, // 0x3000
        PAGE_READWRITE,          // 0x04
    );
    
    if NT_SUCCESS(status) {
        println!("Allocated at {:?}", base_addr);
        
        // Don't forget to free!
        let mut free_size: SIZE_T = 0;
        nt_free_virtual_memory(
            NtCurrentProcess(),
            &mut base_addr,
            &mut free_size,
            MEM_RELEASE, // 0x8000
        );
    } else {
        println!("Failed: 0x{:08X}", status as u32);
    }
}
```

### Process Memory Read/Write

```rust
use syscalls::*;

unsafe {
    let process_handle: HANDLE = /* ... */;
    let remote_addr: PVOID = /* ... */;
    
    // Read memory
    let mut buffer: [u8; 256] = [0; 256];
    let mut bytes_read: SIZE_T = 0;
    
    let status = nt_read_virtual_memory(
        process_handle,
        remote_addr,
        buffer.as_mut_ptr() as PVOID,
        buffer.len(),
        &mut bytes_read,
    );
    
    // Write memory
    let data: [u8; 16] = [0x90; 16]; // NOP sled
    let mut bytes_written: SIZE_T = 0;
    
    let status = nt_write_virtual_memory(
        process_handle,
        remote_addr,
        data.as_ptr() as PVOID,
        data.len(),
        &mut bytes_written,
    );
}
```

### Change Memory Protection

```rust
use syscalls::*;

unsafe {
    let mut addr = some_address as PVOID;
    let mut size: SIZE_T = 0x1000;
    let mut old_protect: ULONG = 0;
    
    let status = nt_protect_virtual_memory(
        NtCurrentProcess(),
        &mut addr,
        &mut size,
        PAGE_EXECUTE_READWRITE, // 0x40
        &mut old_protect,
    );
    
    if NT_SUCCESS(status) {
        // Memory is now RWX
        // Restore protection when done:
        nt_protect_virtual_memory(
            NtCurrentProcess(),
            &mut addr,
            &mut size,
            old_protect,
            &mut old_protect,
        );
    }
}
```

### Error Handling with NtStatus

```rust
use syscalls::*;

unsafe {
    let status = nt_some_function(/* ... */);
    
    // Check success
    if NT_SUCCESS(status) {
        // OK
    }
    
    // Check specific errors
    match status as u32 {
        0x00000000 => println!("STATUS_SUCCESS"),
        0xC0000005 => println!("STATUS_ACCESS_VIOLATION"),
        0xC0000008 => println!("STATUS_INVALID_HANDLE"),
        0xC000000D => println!("STATUS_INVALID_PARAMETER"),
        0xC0000022 => println!("STATUS_ACCESS_DENIED"),
        0xC0000034 => println!("STATUS_OBJECT_NAME_NOT_FOUND"),
        _ => println!("Unknown status: 0x{:08X}", status as u32),
    }
    
    // Or use the error module
    let err = NtStatus::from(status);
    println!("Error: {}", err);
}
```

## Architecture Details

### How It Works

1. **PEB Parsing**: At runtime, the library parses the Process Environment Block (PEB) 
   to locate `ntdll.dll` in memory.

2. **Export Enumeration**: It reads ntdll's export table and collects all `Zw*` functions 
   (which are syscall stubs).

3. **Syscall Number Resolution**: Functions are sorted by address. The index in this 
   sorted list equals the syscall number (this is how Windows assigns syscall numbers).

4. **Hash-based Lookup**: Function names are hashed using a ROR8-based algorithm with 
   a random seed. This provides obfuscation - the actual function names don't appear 
   in the binary.

5. **Direct Syscall**: Instead of calling `ntdll!NtXxx`, the generated code directly 
   executes the `syscall` instruction with the resolved number.

### x64 Calling Convention

```
Parameters 1-4: RCX, RDX, R8, R9 (but syscall clobbers RCX, so param1 goes to R10)
Parameters 5+:  Stack at RSP+0x28, RSP+0x30, ...
Syscall number: EAX
Return value:   RAX (NTSTATUS)
```

### x86/WoW64 Calling Convention

```
All parameters: Stack (stdcall)
Syscall number: EAX
Stack pointer:  EDX
Instruction:    SYSENTER (or call to WoW64 gate)
```

## Important Notes

### Thread Safety

The syscall list is populated lazily on first use and stored in a global static. 
The population is not thread-safe by design (to avoid synchronization overhead). 
In practice, this is rarely an issue as the list is typically populated early 
in program execution.

### Pointer Parameters

Many syscalls take pointer parameters that are both input and output (e.g., 
`RegionSize` in `NtAllocateVirtualMemory`). Always use mutable references:

```rust
// WRONG - won't compile
let region_size: SIZE_T = 0x1000;
nt_allocate_virtual_memory(..., &region_size, ...);

// CORRECT
let mut region_size: SIZE_T = 0x1000;
nt_allocate_virtual_memory(..., &mut region_size, ...);
```

### Handle Values

Use the provided constants and macros:

```rust
NtCurrentProcess()  // Returns (HANDLE)-1 for current process
NtCurrentThread()   // Returns (HANDLE)-2 for current thread
```

## Troubleshooting

### "Syscall not found" (returns 0xFFFFFFFF)

The function hash doesn't match any export in ntdll. This can happen if:
- The function doesn't exist on this Windows version
- The seed was changed after compilation
- ntdll is corrupted or hooked in a way that breaks export enumeration

### STATUS_ACCESS_VIOLATION on syscall

Usually indicates incorrect parameters:
- Null pointer where valid pointer expected
- Invalid handle value
- Misaligned buffer

### Different behavior than ntdll

Some ntdll functions do additional validation before the syscall. Direct syscalls 
skip this validation, which can cause different error codes or behavior.
